# Happening – Backend

Happening Backend provides the REST APIs and business logic powering the Happening city events discovery and booking platform.

## Tech Stack
- Java
- Spring Boot
- Spring Security
- JWT authentication
- Spring Data JPA
- MySQL
- Maven

## Key Features
- User registration and authentication
- Role-based access control
- Event creation, management, and discovery
- Event booking management
- Favorites and reviews
- Organizer and administrator operations
- RESTful API integration with the React frontend

## Project Structure
The backend follows a layered architecture with controllers, services, repositories, entities, and security components to support maintainability and separation of concerns.
